# Security Policy

## Supported Versions

Only the latest release of this fork receives security fixes. Please make sure
you are running the most recent release (or the current `dev` branch) before
reporting an issue.

## Reporting a Vulnerability

Please report security vulnerabilities via
[GitHub Security Advisories](https://github.com/CyberAZE-community/Havoc/security/advisories/new)
for this repository.

If that is not possible, open a regular
[issue](https://github.com/CyberAZE-community/Havoc/issues) with minimal detail
and ask for a maintainer to follow up privately.

Please do not disclose vulnerabilities publicly until a fix has been released.
